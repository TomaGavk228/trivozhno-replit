# Telegram-бот «між думками»

Гілка `feat/gemini-3-5-flash-lite-2026-10-06`. Один запит до **Gemini 3.5 Flash-Lite** формує відповідь, стан розмови, оновлення пам'яті й посилання на використані книжкові джерела. Промт зберігає манеру «кент у Telegram»: коротка розмовна українська, поради на прохання, без вигаданої біографії. Бот має сам додавати зміст у розмову: думку, спостереження чи доречне питання. Коротка згода й поганий настрій не є приводом закривати тему порожніми фразами.

Книжки знову працюють у чаті: для психологічної поради чи пояснення бот знаходить відповідні матеріали й просить модель застосувати їх до ситуації власними словами. Якщо джерел немає, він не повинен вигадувати методику або книжку. Пошук локальний і лексичний, без окремого AI-виклику. Достовірність перефразування потребує ручної перевірки.

Прибрано Groq/Z.ai, їхні квоти й перемикачі, старі тести/CI та документи попередньої архітектури. Меню, зізнання, щоденник настрою й нагадування залишаються. Міграція прибирає чотири невикористані службові поля й додає строк доставки; переписка, факти, книжки, настрій та нагадування не видаляються.

## Оновлення Replit

Зупини Run. Якщо ти вже на цій гілці:

```bash
git fetch origin
git switch feat/gemini-3-5-flash-lite-2026-10-06
git pull --ff-only
bash scripts/run.sh
```

Якщо гілки локально немає: `git switch --track origin/feat/gemini-3-5-flash-lite-2026-10-06`. Незбережені локальні зміни спочатку збережи; примусовий reset не потрібний. `run.sh` виконає restore, Release-збірку, міграції й запуск.

Secrets: `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY`. Для зізнань — `CONFESSIONS_CHANNEL_ID`, або `FEATURE_CONFESSIONS=false`. `.env` автоматично не читається. Старі `AI_PROVIDER`, `GROQ_*`, `ZAI_*`, `GEMINI_MAX_CONCURRENCY` більше не використовуються: їх можна видалити. Паралельність задає один `AI_MAX_CONCURRENCY=2`. Решта необов'язкових параметрів — у [.env.example](.env.example).

## Книжки

Якщо вони вже імпортовані, повторно завантажувати PDF не потрібно. Після цього оновлення освіжи індекс:

```bash
bash scripts/bot.sh reindex-books
bash scripts/bot.sh list-books
bash scripts/bot.sh search-books --query 'як побороти тривожність'
```

Для першого імпорту додай власні PDF до `data/books` і виконай `bash scripts/bot.sh import-books --path ./data/books`. У Git книжок немає. Після імпорту текст і сторінки зберігаються в PostgreSQL, PDF на диску для чату не потрібні. Скановані PDF потребують окремого OCR.

## Контекст і пам'ять

- До 32 попередніх обмінів поточної сесії; у контексті лише реально доставлений текст бота. Недоставлені частини не стають спогадом про розмову.
- Пам'ять до 3000 приблизних токенів: профіль, важливі люди, уподобання, доречні давні факти й цитати, останній завершений стан розмови. Вона зберігається між сесіями й рестартами.
- До 6 нових фактів за одну відповідь, до 256 у профілі. Кожен новий факт має дослівну цитату поточної репліки; вигаданий текст не приймається. Ідентичність має пріоритет, виправлення замінюють факт за стабільним ключем. Це обмежена пам'ять, не гарантія запам'ятати абсолютно все.
- Загальний вхідний бюджет — 32000 приблизних токенів зі схемою JSON; поточний текст зберігається повністю. Вихідний бюджет — 3000, thinking — `LOW`, температура — 1. Параметри зчитуються з `src/Bot/Resources/Chat/generation.json`.
- Вихід із чату зберігає пам'ять. «Очистити пам'ять» видаляє переписку, факти, підсумки й стиль; «Видалити дані» очищає також інші записи людини. Щоденник настрою й зізнання не включаються в контекст чату.

## Доставка й квоти

Короткі рядки стають окремими Telegram-повідомленнями, до 6 за відповідь. Код, списки й довгі пояснення зберігаються блоком. Швидкі вхідні репліки об'єднуються; нова репліка скасовує застарілий AI-запит і недоставлені частини. Вже прийнятий Google запит може врахуватися у квоті навіть після скасування.

Два воркери доставки не тримають користувацьке блокування під час HTTP. Через 90 секунд зависла доставка переходить у `delivery_unknown`; невизначені надсилання не повторюються автоматично. Журнал показує факт лише підтвердженої доставки. Уже відправлене або прийняте Telegram повідомлення не можна відкликати цим механізмом.

Ліміти акаунта визначає Google AI Studio. Бот враховує 429, `Retry-After`/`RetryInfo`, відрізняє денну квоту й журналює фактичні токени. Він не підмінює квоти Google власними припущеннями про безкоштовний тариф.
