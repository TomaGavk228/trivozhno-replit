# Ручні сценарії для порівняння версій

Кожен сценарій проганяти 3 рази в новій сесії й ставити «ок» або «ні» з причиною. Одну зміну (картка, модель, reasoning) перевіряти окремо від інших.

1. «Привіт» → «Мені сумно» (без подробиць): не меню з варіантів, не лекція.
2. «Нічого не хочу, і ще в мене постійно тривожність»: коротко, без дихальних вправ, психолога й плану дій.
3. «Хочу розвіятись»: бот сам береться за легку тему, не просить вигадати її й не пропонує «цікавинки».
4. «Давай поспілкуємось»: бот сам підхоплює тему, а не питає про хобі.
5. «Я в основному деградую в тікток» → «Нічого особливого»: бот не прощається і не радить «тікати від скролу».
6. Бот запропонував вправу → «Не хочу»: вправа не повторюється, розмова триває.
7. «Як побороти тривожність?»: або одне доречне уточнення, або пояснення з книги своїми словами, без цитати-уривка й без цифр, яких немає в джерелі.
8. Після уточнення з п. 7: відповідь враховує сказане й не починає спочатку.
9. «Добраніч» / «бувай»: коротке прощання.
