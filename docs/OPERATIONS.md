# Обслуговування

```bash
bash scripts/bot.sh check-config
bash scripts/bot.sh metrics
bash scripts/bot.sh inspect-outbox
bash scripts/bot.sh list-books
bash scripts/bot.sh audit-books
```

Метрики: inbox, ai, outbox, unknown, errors, ai24h і токени за моделями. Логи не містять текстів розмов, книжок, нотаток, зізнань, ключів чи повних HTTP URL. EF і HttpClient payload-логи вимкнені.

## Міграція

`scripts/run.sh` застосовує міграції перед стартом. Нове оновлення прибирає службові колонки MoodConsentShown, MoodContextEnabled, SummaryNextAt, QueueNoticeShown, додає Outbox.LeaseUntil і переводить старий ConfirmMoodContext у Settings. Старі таблиці й міграції збережені. Самі переписки, факти, книги, настрій та нагадування не видаляються. Зупини попередній екземпляр перед оновленням.

## Доставка

Два воркери з одним механізмом claim зберігають порядок адресата/частин. Блокування людини не тримається під час HTTP. Telegram rate gate: до 20/с загалом, пауза 1,1 с у приватному чаті, 3,1 с для каналу. Lease доставки — 90 с. Зависла відправка переходить у delivery_unknown без рестарту; її не відправляють сліпо повторно.

При невизначеній звичайній відповіді наступні частини скасовуються, чат можна продовжити. Частково доставлена відповідь має partial_delivery/interrupted, і лише її доставлений текст використовується в історії. Нове повідомлення скасовує queued-частини; вже відправлені або прийняті Telegram частини відкликати не можна.

Для невизначеного зізнання зупини Run, перевір канал і ID у inspect-outbox. Якщо частина є:

```bash
bash scripts/bot.sh mark-delivered 123 --message-id 456
```

Якщо її вирішено повторити після перевірки:

```bash
bash scripts/bot.sh retry-delivery 123 --accept-duplicate-risk
```

Для відомої failed-відмови прапорець не потрібний. Telegram sendMessage не має універсального ключа ідемпотентності; невизначений повтор може створити дубль. Операторські команди не видаляють і не редагують канал.

## Книжковий індекс

```bash
bash scripts/bot.sh import-books --path ./data/books
bash scripts/bot.sh reindex-books
bash scripts/bot.sh search-books --query 'як впоратися з тривогою'
bash scripts/bot.sh deactivate-book 123
```

Reindex змінює лише пошукові терміни, без AI-запитів і змін тексту/сторінок. Після зміни Lexicon освіжи вже імпортовані джерела. У search-books виводяться тільки назви, id, сторінки й score. Для PDF без текстового шару потрібен окремий OCR. Лексичний пошук не розуміє всі перефразування.

## Зберігання

Профіль і вся переписка зберігаються в PostgreSQL до очищення пам'яті/видалення даних; вихід із чату їх не стирає. Факти профілю обмежені 256; вікно пошуку старих епізодів — 2048 повідомлень. Записи настрою й зізнання не читаються в чат. Технічний usage без текстів і user id — 2 дні, кінцеві inbox/outbox — 7 днів, occurrence нагадувань — 30 днів; планове очищення виконується, коли бот працює.

Після кінцевої звичайної доставки текст/маршрут outbox стирається. Для failed/unknown-зізнань він лишається до розв'язання. Повне видалення профілю каскадно очищає його таблиці й персональний inbox; пізня AI-відповідь не створить їх знову. Вже прийняте Telegram надсилання може дійти під час видалення. Старі Telegram-повідомлення, копії в Google й backups хостингу цим не видаляються.

Застосунок не керує backups хостингу. Відновлення повного старого дампа може повернути видалені дані: не відновлюй його поверх живої бази без процедури повторного застосування видалень. Відновлення книг у чисту базу не повертає особисті записи.

## Запуск і діагностика

Для channel-id або delete-webhook зупини інший poller. Видалення webhook зберігає pending updates. Одночасні запуски з одним токеном/БД блокуються advisory lock; при втраті lock-з'єднання процес завершується. `/api/healthz` — процес живий; `/api/readyz` — runtime і DB доступні, це не перевірка квоти Google.

Якщо не запускається SDK, перевір `replit.nix`, ICU/OpenSSL і перезапусти Shell. Не вмикай DOTNET_SYSTEM_GLOBALIZATION_INVARIANT: українська локалізація потрібна. 401/403 Google — ключ/права, 404 — model, 429 — фактична квота. 401/409 Telegram — токен, webhook або інший poller. Зміни NuGet потребують оновлення packages.lock.json і збірки. Бот не запускає автоматичних тестів.
