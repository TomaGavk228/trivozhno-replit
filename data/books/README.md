Додай сюди власні PDF «Стіни в моїй голові» та «Для стосунків потрібні двоє».
В архіві книжок немає. PDF не повинні потрапляти у Git або Docker-образ.

Імпорт у базу з поточного DATABASE_URL:

```bash
bash scripts/bot.sh import-books --path ./data/books
bash scripts/bot.sh list-books
```

Після імпорту робота бота не залежить від наявності PDF на диску.
Порожні/скановані сторінки позначаються у звіті; OCR не виконується.
